SEO Basics for a New Website

Educational article · Updated 7 November 2026

← Back to all guides

Search engine optimisation (SEO) is the practice of improving a website so search engines can understand its pages and people can find relevant information. SEO does not guarantee a particular ranking or a fixed amount of traffic.

Publish pages that answer real questions

Start by identifying the questions your intended readers ask. Create original pages that answer those questions clearly, add examples where useful and avoid repeating the same information across many thin pages.

Use descriptive page titles

Give each important page a unique, accurate title. A title should describe the page topic naturally. Avoid keyword stuffing and misleading promises.

Organise headings and navigation

Use one clear main heading, then organise sections with descriptive subheadings. Make sure visitors can reach important pages from the main navigation and related articles can link to each other where useful.

Make the website usable on mobile

Check that text is readable, links are easy to tap, images fit the screen and the page does not shift unexpectedly. Compress images and avoid unnecessary scripts that slow down the site.

Help search engines discover pages

Use a sitemap where appropriate and submit it through Google Search Console. Check indexing reports for errors. Submitting a URL does not guarantee that Google will index it.

Measure and improve

Search Console can show queries, impressions, clicks and indexing information for verified properties. Use this data to find pages that need clearer answers or better titles. Allow time for changes to be crawled and evaluated.

SEO checklist

  • Each important page has a distinct purpose.
  • Content is original, accurate and useful.
  • Navigation and internal links work.
  • Pages load and display properly on mobile.
  • Broken links and placeholder pages are removed.
  • Privacy and contact information are easy to find.

Conclusion

Good SEO begins with a useful website, not tricks. Focus on readers first, make pages technically accessible and use search data to guide gradual improvements.
