SEO Basics for a New Website: A Practical Step-by-Step Guide

Educational article · 13 min read · Growth Hardik

← Back to all guides

Author: Hardik VaghoraOriginally published: 1 November 2026Last updated: 20 November 2026

Search engine optimisation (SEO) is the practice of making a website easier for search engines to discover and understand while making its pages genuinely useful to people. For a new website, the best starting point is not a collection of technical tricks. It is a clear set of pages that answers the questions visitors actually have, supported by a site structure that people and crawlers can follow.

What SEO can and cannot do

SEO can help relevant pages become discoverable in search. It does not guarantee indexing, a particular ranking, traffic volume or sales. Search systems change, competitors publish new information and demand varies. Treat SEO as ongoing website improvement rather than a one-time setup.

1. Start with search intent

Search intent is the purpose behind a query. A person searching “what is website hosting” probably needs an explanation. Someone searching for “website designer in Morbi” may be comparing local providers. A page should answer the need suggested by its topic. Before writing, note the likely reader, their question, what a complete answer should include and what useful next step may follow. Do not create several pages that repeat the same answer with only a location or keyword changed.

2. Create content that helps a reader complete a task

A useful article explains a subject accurately, gives enough context and helps the reader decide what to do next. Add examples, steps, limitations and definitions where they genuinely help. If you have first-hand experience, describe what you did and what you learned without inventing results or presenting one experience as universal. For example, an article about setting up a contact page should explain what contact details to show, which form fields are necessary, what happens after submission and how to test the form. Simply saying “every website needs a contact page” does not answer the practical questions.

3. Organise each page clearly

Use one descriptive main heading (H1), followed by logical H2 and H3 headings. Keep paragraphs focused. Use numbered steps for a process and bullet lists for related items. Headings should describe the content that follows rather than repeat keywords. A useful page title tells readers what the page covers. Write a distinct title and meta description for each important page. A meta description may help summarise a page in search results, but search engines can choose a different snippet.

4. Make internal links useful

Internal links connect related information and help visitors find their next answer. Link a beginner guide to a more detailed topic, link a service explanation to the relevant contact page and provide a clear route back to the blog index. Use descriptive anchor text. “Read the SEO checklist” tells a visitor more than “click here”. Test links after publishing, including links in article text, navigation, breadcrumbs and footers. Remove links to pages that do not exist.

5. Check basic technical accessibility

  • HTTPS: Use a secure version of the site and keep URL versions consistent.
  • Mobile layout: Make text readable and controls easy to tap on smaller screens.
  • Readable content: Keep important information as selectable text, not only in images.
  • Images: Use appropriate file sizes and meaningful alternative text for informative images.
  • Canonical URLs: Set a correct canonical URL where duplicate URL versions may exist.
  • Indexing directives: Check that important public pages are not accidentally marked noindex.
  • Performance: Reduce unnecessarily large images and scripts that delay the page.

6. Use a sitemap and robots.txt correctly

A sitemap lists URLs that a site owner wants search engines to discover. Keep it limited to canonical, public pages that are intended to be indexed. Update it when important pages are added or removed. A robots.txt file gives crawler instructions. It is not a reliable way to remove a URL from search results, and blocking a resource can prevent a crawler from rendering a page properly. Check that the file does not accidentally block important pages or assets.

7. Use Google Search Console to inspect the site

Search Console helps site owners understand how Google Search interacts with a website. Verify the correct property, submit the sitemap and use URL Inspection for important pages. Review indexing reports and read the reason for any excluded or errored URL. Submitting a sitemap or requesting indexing does not guarantee that a page will be crawled, indexed or ranked. Check that the page is accessible, has useful content and is linked from other relevant pages on the site.

8. Measure progress carefully

Search Console can show queries, impressions, clicks and average position for eligible search data. Compare similar date ranges and consider seasonality, changes in demand and recent site updates. If a page receives impressions but few clicks, check whether its title and description accurately communicate the answer. If visitors arrive but do not find what they need, improve the page itself rather than simply adding more keywords.

A practical example: improving a service page

Imagine a small business website with a page titled “Our Services” and only a short list of offerings. A more useful page would explain each service, who it is for, what is included, what information a customer should prepare and how to ask a question. It could link to a relevant educational guide and a working contact page. This improvement helps visitors understand the service. It also gives search engines clearer page context. It does not guarantee a ranking, but it makes the page more useful than a generic list.

A new-site SEO checklist

  1. List the important pages and the purpose of each page.
  2. Identify real questions from the intended audience.
  3. Write original content that answers those questions fully.
  4. Give each page a descriptive title, meta description and clear H1.
  5. Connect related pages with descriptive internal links.
  6. Check mobile usability, HTTPS and loading performance.
  7. Review canonical URLs, sitemap.xml and robots.txt.
  8. Test important pages and links after every major update.
  9. Verify the site in Search Console and review indexing reports.

Conclusion

A strong SEO foundation is a useful, accessible website with clear pages and a structure visitors can understand. Focus on the reader’s question first, then make the page easy to navigate and technically accessible. Use Search Console to learn how search systems see the site, and make measured improvements over time.
